# 千山 · A Thousand Mountains

一幅会呼吸的水墨山水。滚动,即是在山中行旅,**没有尽头**。

实时光线步进(raymarching)渲染,无任何贴图、无外部资源、无构建步骤 —— 一个全屏三角形 + 一支片元着色器。

---

## 运行

```bash
npm run dev
```

打开 http://localhost:5173 。任何静态服务器都可以,例如 `npx serve`。

## 画质档位

渲染器按帧耗时自动调节内部分辨率与步进预算。也可以用查询参数强制指定:

| 参数 | 行为 |
| --- | --- |
| `?q=high` | 150 步,最高内部分辨率 |
| `?q=medium` | 96 步,原生分辨率 |
| `?q=low` | 44 步,降采样 —— 适合集显或低端设备 |
| `?q=auto` | 默认,自适应 |

## 操作

- **滚动** —— 沿路径前行,山与云在雾中依次展开, endlessly
- **移动指针** —— 视角微调
- **右上角「乐声」** —— 开关程序生成的古琴配乐
- 页面遵循 `prefers-reduced-motion`

## 无限行旅

没有尽头,也没有「到头」这件事。

滚动条本身并不承载位置:页面只有 6 屏高的占位,滚动时把位移累加进一个虚拟里程,随后立刻把 `scrollY` 重置回中段。因为画面由虚拟里程驱动、诗文层由同一里程定位,重置在视觉上完全无感 —— 滚动条会停在原地,而山一直在走。

左下角的「行 N 里」是真实累加的里程,回滚会减回去。

相机的爬升与横向摆动都用**有界周期函数**而非线性累加(`sin(uTravel * 0.0055)` 之类),否则走远了相机会一路爬到天上。

诗文取自 26 组公版古诗,按 `idx × 7` 步长取用(7 与 26 互质,所以走完一轮才会重复)。5 个诗格循环复用,随里程推入推出、边缘淡入淡出。

## 乐声

**不加载任何音频文件。** 全部由 Web Audio 现场合成:

- **古琴** —— Karplus-Strong 弦模型。噪声激励送入延时线,反馈端接一阶低通(`0.5 × (cur + next)`),高频随时间衰减,弦的包络自然形成。拨弦位置用梳状滤波在激励端制造,得到比吉他更亮、更「木」的起音。
- **五声音阶** —— 宫商角徵羽,以 D 为宫(徵调式)。乐句用加权随机游走生成,偶尔跳进,而不是随机撒音 —— 这样才有旋律的轮廓。
- **泛音** —— 泛音列(2×、3×)随机叠加,音量压得很低,这是古琴音色辨识度的关键。
- **散音** —— 约 16% 概率延长到 5.4 秒的长音,对应空弦。
- ** reverb ** —— 卷积混响的脉冲响应也是程序生成的(指数衰减白噪声,3.4 秒),不是采样。
- **底噪** —— 两个失谐正弦 + 一个三角波构成持续低音,叠 0.055Hz 的慢 LFO;另有带通滤波白噪声作风声,同样受慢 LFO 调制。
- **随景联动** —— 滤波器截止频率跟随里程缓慢开合,像穿过云层时声音变亮。

浏览器要求用户手势后才能起声,所以第一次交互(点击 / 按键 / 触摸)时才启用;显式静音会记进 `localStorage`,下次不再自动播放。

## 画面是怎么做出来的

### 地形

高度场由四层叠加:

- **主山脉** —— 3 阶 ridged multifractal,频率 `0.0055`、振幅 `150`。斜率约 28°–45°,这是关键:波长与振幅之比决定了山是"陡壁"还是"山"。早期版本波长只有 57、振幅 105,坡度达 75°,渲染出来是一堆被切掉顶部的抽象条纹,而不是山。
- **支脉** —— 更高频的 ridged,提供次级山体细节
- **基座** —— 极低频 fbm,控制整片山脉的起伏与延伸
- **颗粒** —— 单层噪声,给表面微起伏

这些参数不是猜的,是把噪声函数在 Node 里重写一遍、采样 4 万个点、统计高度分位数与坡度分布定出来的。

### 云气与留白

这是水墨的命门。雾不是"加一层白",而是沿视线**积分**出来的:采样点越低、路径越长,累积的雾越浓,于是远山被"洗"进纸白,近山才留得住墨。采样用 `t²` 非均匀分布,近处密、远处疏。

同样关键的一点:雾的浓度必须由**实际命中距离**决定,而不是远裁剪面距离。用后者会让近处的山也一起变灰,整个画面发死。

### 皴法

山体纹理顺着局部等高线方向生成:取法线水平分量的垂线作为「沿等高线」坐标,让噪声在这个坐标上高频、在高度方向低频,得到顺坡而下的竖向笔触,而不是等高线状的横条纹。叠三层:底皴、细皺、以及少数几道浓墨重笔。

### 水面

解析求交而非光线步进。水体本身几乎是纸白,只保留稀疏的横向墨线(随距离淡出)与菲涅耳加权的山影倒影。水面向远处**直接溶进天空色**,避免地平线出现硬边。

### 留白的取舍

地平线压到画面下方约 36%,水占下三分之一,山占上三分之二 —— 高远构图。云气只填到约 46 单位高度,峰顶从雾里露出来。

## 诗文

取自公版古诗,随行旅逐段浮现:柳宗元《江雪》、王维《山居秋暝》《终南别业》《汉江临泛》《青溪》、苏轼《题西林壁》、常建《题破山寺后禅院》、陶渊明《饮酒》、李白《夜宿山寺》、杜甫《望岳》、孟浩然《宿建德江》、刘长卿《苕溪酬梁耿别业见寄》、元好问《颍亭留别》、王勃《滕王阁序》。

开篇取「千山鸟飞绝」—— 也是飞鸟每 34 秒掠过云海一次的出处。

## 技术

- WebGL2,零依赖,零构建,零外部资源(含音频)
- 单 pass raymarching,自适应分辨率与步进预算
- 宣纸纤维、暗角、墨色微偏朱砂的后处理
- 附带一个零依赖的本地静态服务器(`server.mjs`)

## 已知限制

- 着色器用 `float32` 算世界坐标。里程极大时(约百万像素级滚动)噪声函数的 `fract()` 会开始损失精度,地表可能出现轻微重复。正常使用不会碰到。
- 帧率未在真实 GPU 上验证过 —— 开发环境只有 SwiftShader 软渲染。
