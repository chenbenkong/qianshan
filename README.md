# 千山 · A Thousand Mountains

一幅会呼吸的水墨山水。滚动,即是在山中行旅。

实时光线步进(raymarching)渲染,无任何贴图、无外部依赖、无构建步骤 —— 一个全屏三角形 + 一支片元着色器。

---

## 运行

```bash
npm run dev
```

打开 http://localhost:5173 。任何静态服务器都可以,例如 `npx serve`。

## 画质档位

渲染器按帧耗时自动调节内部分辨率与步进预算。也可以用查询参数强制指定:

| 参数 | 行为 |
| --- | --- |
| `?q=high` | 150 步,最高内部分辨率 |
| `?q=medium` | 96 步,原生分辨率 |
| `?q=low` | 44 步,降采样 —— 适合集显或低端设备 |
| `?q=auto` | 默认,自适应 |

## 操作

- **滚动** —— 沿路径前行,山与云在雾中依次展开
- **移动指针** —— 视角微调
- 页面遵循 `prefers-reduced-motion`

## 画面是怎么做出来的

### 地形

高度场由四层叠加:

- **主山脉** —— 3 阶 ridged multifractal,频率 `0.0055`、振幅 `150`。斜率约 28°–45°,这是关键:波长与振幅之比决定了山是"陡壁"还是"山"。早期版本波长只有 57、振幅 105,坡度达75°,渲染出来是一堆被切掉顶部的抽象条纹,而不是山。
- **支脉** —— 更高频的 ridged,提供次级山体细节
- **基座** —— 极低频 fbm,控制整片山脉的起伏与延伸
- **颗粒** —— 单层噪声,给表面微起伏

### 云气与留白

这是水墨的命门。雾不是"加一层白",而是沿视线**积分**出来的:采样点越低、路径越长,累积的雾越浓,于是远山被"洗"进纸白,近山才留得住墨。同时雾有噪声调制,所以会结成块状云气而非均匀灰纱。

同样关键的一点:雾的浓度必须由**实际命中距离**决定,而不是远裁剪面距离。用后者会让近处的山也一起变灰,整个画面发死。

### 皴法

山体纹理顺着局部等高线方向生成:取法线水平分量的垂线作为「沿等高线」坐标,让噪声在这个坐标上高频、��高度方向低频,得到顺坡而下的竖向笔触,而不是等高线状的横条纹。叠三层:底皴、细皺、以及少数几道浓墨重笔。

### 水面

解析求交而非光线步进。水体本身几乎是纸白,只保留稀疏的横向墨线(随距离淡出)与菲涅耳加权的山影倒影。水面向远处直接溶进天空色,避免地平线出现硬边。

### 留白的取舍

地平线压到画面下方约 36%,水占下三分之一,山占上三分之二 —— 高远构图。云气只填到约 46 单位高度,峰顶从雾里露出来。

## 诗文

取自公版古诗,随滚动逐段浮现:

- 柳宗元《江雪》—— 「千山鸟飞绝」,也是鸟群掠过时的出处
- 王维《山居秋暝》
- 苏轼《题西林壁》
- 常建《题破山寺后禅院》
